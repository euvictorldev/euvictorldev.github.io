# Project: Victor's High-Conversion Portfolio

## What This Is
A premium, high-conversion landing page/portfolio designed to lead clients directly to WhatsApp or Discord. It features a cinematic hero section with a video background, glassmorphic UI, and emerald green accents on a deep black theme.

## Core Value
Direct conversion through a professional, agile, and resilient visual identity that communicates complex services in simple, accessible language.

## Context
- **Target Audience**: Clients looking for professional websites, automation bots (WhatsApp/Telegram/Discord), custom apps, and cloud security.
- **Visual Identity**: Deep Black (#0D0D0D) with Emerald Green (#00FF41) accents. Pulsating "Available for projects" indicator.
- **Hero Section**: Fullscreen looping video, glassmorphic navigation, "Instrument Serif" typography.

## Requirements

### Active
- [ ] **Hero Section**: Fullscreen video background with "Instrument Serif" typography and fade-rise animations.
- [ ] **Navigation**: Glassmorphic top bar with "Victor" logo, links (Home, Services, Portfolio, About), and "Contact" CTA.
- [ ] **Availability Indicator**: Pulsating green dot with "Disponível para novos projetos" text.
- [ ] **Services Section**: Simple cards for:
    - Sites Profissionais
    - Robôs de Atendimento
    - Aplicativos Sob Medida
    - Segurança e Nuvem
    - Suporte e Manutenção
- [ ] **Portfolio Section**: Showcase of 5 specific projects (HadesPay, Tô Brocado, etc.) using high-quality mock links.
- [ ] **About Me Section**: History, Training (IFPA/Solyd), and Philosophy.
- [ ] **Conversion**: Parametrized links for WhatsApp and Discord.
- [ ] **Performance**: 100% Mobile responsive and ultra-fast loading.

### Out of Scope
- [ ] **Blog**: Not included in the initial conversion-focused version.
- [ ] **Backend/CMS**: Initial version will be a static/client-side React app.

## Tech Stack
- **Framework**: React + Vite + TypeScript
- **Styling**: Tailwind CSS + Vanilla CSS (for liquid glass)
- **Components**: shadcn/ui
- **Icons**: Lucide React
- **Fonts**: Instrument Serif (Display), Inter (Body)
- **Animations**: CSS Keyframes / Framer Motion

# Research: Redesign /servico/sites-que-vendem

## Key Findings

### 1. Conversion-Optimized Pricing Page Structure
- **3 tiers max** — avoids decision paralysis
- **Highlight recommended** plan with visual emphasis (badge "Recomendado", border glow)
- **Progressive disclosure** — use Accordion for details (structure, requirements) instead of showing everything
- **Benefit-first copy** — translate features into outcomes ("you get X" not "we do X")

### 2. Brazilian Market Copy Patterns
- WhatsApp CTA is the #1 converter in BR market — make it prominent on every plan
- Direct but warm tone — avoid corporate jargon
- Social proof critical — even without testimonials, authority signals work (tech logos, "X projetos entregues")
- FAQ section essential for objection-breaking before the CTA

### 3. Component Architecture (shadcn available)
Already installed and usable:
- `Tabs` — for switching between plan details
- `Accordion` — for FAQ + progressive disclosure of requirements/tech
- `Badge` — for "Recomendado", "Mais Popular" labels
- `Card` — for plan cards
- `Separator` — for visual breaks
- `Tooltip` — for explaining technical terms

### 4. Content Condensation Strategy
Original content has ~1500 words. Target: ~600 words visible, rest behind accordions.

**Keep prominent (above fold):**
- Hero headline + subheadline
- 3 plan cards with price, ideal-for, key features (3-4 max), CTA
- "Recomendado" badge on Landing Page Express

**Behind accordions/tabs (progressive disclosure):**
- Full feature lists per plan
- Project requirements (Parte 1/2/3)
- Detailed tech stack
- Monthly maintenance plan (separate card below pricing)

**Combine/remove:**
- "Adicionais e Upgrades" → inline as badges/tooltips on relevant plans
- "Por que me escolher" → condensed to 2-line trust bar with icons
- "Tecnologias de Elite" → tech pills at bottom, small

### 5. Layout Decision
Create a dedicated `SitesQueVendem.tsx` component that renders when slug === "sites-que-vendem", 
keeping the generic `ServiceDetail.tsx` for other services. This allows a completely custom layout
without breaking existing service routes.
